# tg_export

Экспорт сообщений и медиа из чатов, групп и каналов Telegram в JSONL.

## Быстрый старт

1. Скачайте и распакуйте архив для своей системы из
   [Releases](https://github.com/avissian/tg_export/releases).
   Доступны Windows и Linux (x86-64), macOS (Apple Silicon).
2. Получите `APP_ID` и `APP_HASH` на [my.telegram.org](https://my.telegram.org)
   → *API development tools*. Рядом с программой создайте файл `.env`:

   ```env
   APP_ID=1234567
   APP_HASH=abcdef0123456789abcdef0123456789
   ```

3. Откройте терминал в этой папке и запустите:

   ```sh
   ./tg_export
   ```

   В Windows: `.\tg_export.exe`.
4. Отсканируйте QR-код: Telegram → *Настройки → Устройства → Подключить устройство*.
   Выберите чат и количество последних сообщений (`0` — вся история).

В списке чатов: `n` или Enter — следующая страница, `p` — предыдущая, `q` — выход.
При следующих запусках входить заново не нужно.

## Флаги запуска

| Флаг | Что делает |
|------|------------|
| `--no-media` | Не скачивать вложения, сохранить только JSONL сообщений |
| `--no-stickers` | Не скачивать стикеры, включая анимированные и видео |
| `--no-audio` | Не скачивать аудио, голосовые и видеокружочки |
| `--code-auth` | Войти по коду вместо QR; нужен `PHONE=+79991234567` в `.env` |
| `--verbose`, `-v` | Подробный лог для диагностики |

Флаги можно сочетать:

```sh
./tg_export --no-stickers --no-audio
./tg_export --no-media
```

Без флагов скачиваются все вложения. Отключение скачивания **не меняет JSONL**:
все сообщения, подписи, `media_type` и `media_file` остаются, даже если файла нет.
Уже скачанные файлы не удаляются.

## Результат

В папке `exports/<название чата>/` появятся:

- `messages.jsonl` — по одному сообщению на строку, от новых к старым;
- `media/` — вложения (при `--no-media` папка может быть пустой).

Экспорт можно прервать через `Ctrl+C`. При повторном запуске JSONL записывается
заново, а уже скачанные файлы повторно не загружаются.

## Если не подключается

Добавьте прокси в `.env`:

```env
ALL_PROXY=socks5://127.0.0.1:1080
```

Поддерживаются SOCKS5 (`socks5://`, `socks5h://`) и HTTP(S) с `CONNECT`.
MTProxy не поддерживается. Логин и пароль можно указать в адресе;
спецсимволы нужно кодировать, например `#` → `%23`.
Вместо `ALL_PROXY` можно использовать `HTTPS_PROXY` или `HTTP_PROXY`;
`NO_PROXY` задаёт адреса в обход прокси.

Транспорт выбирается автоматически. Если подключение через прокси не работает
или каждый раз долго запускается, попробуйте добавить `TG_TRANSPORT=websocket`
в `.env`. Для подробного лога запустите с `-v`.

Если macOS блокирует скачанную программу:

```sh
xattr -d com.apple.quarantine ./tg_export
```

## Приватность

Утилита обращается только к Telegram, выгрузка хранится локально.
**Не передавайте другим `.env` и `session.json`: последний даёт доступ к аккаунту.**
При утечке завершите соответствующий сеанс в Telegram → *Настройки → Устройства*.

## Сборка из исходников

Нужен Go 1.26.2+:

```sh
go build -o tg_export .
```

Или запуск без отдельной сборки: `go run . --no-media`.
