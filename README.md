# tg_export

Экспорт сообщений и медиа из чатов, групп и каналов Telegram в JSONL.

Утилита подключается к вашему аккаунту Telegram, показывает список доступных
диалогов и выгружает выбранный чат в директорию `exports/<название чата>/`:

- `messages.jsonl` — все сообщения (от новых к старым), по одному JSON на строку;
- `media/` — фото, видео, документы, голосовые, стикеры и т.д.

## Требования

- `APP_ID` и `APP_HASH` — получить на https://my.telegram.org → *API development tools*.

## Установка

Скачайте готовый бинарник для своей платформы со страницы
[Releases](https://github.com/avissian/tg_export/releases):

| Платформа | Архив |
|-----------|-------|
| Windows (x86-64) | `tg_export_windows_amd64.zip` |
| Linux (x86-64) | `tg_export_linux_amd64.tar.gz` |
| macOS (Apple Silicon) | `tg_export_darwin_arm64.tar.gz` |

Распаковать и запустить:

```sh
tar -xzf tg_export_linux_amd64.tar.gz
./tg_export
```

На macOS первый запуск может быть заблокирован Gatekeeper — снять карантин:

```sh
xattr -d com.apple.quarantine ./tg_export
```

## Переменные окружения

Задаются через переменные окружения или файл `.env` в рабочей директории.

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `APP_ID`   | да          | Telegram API ID (число) |
| `APP_HASH` | да          | Telegram API hash |
| `PHONE`    | только для `--code-auth` | Телефон в международном формате, напр. `+79991234567` |

Пример `.env`:

```env
APP_ID=1234567
APP_HASH=abcdef0123456789abcdef0123456789
PHONE=+79991234567
```

Либо передать переменные прямо при запуске:

```sh
APP_ID=1234567 APP_HASH=abc... ./tg_export
```

## Авторизация

По умолчанию — вход по **QR-коду**: в терминале появится QR, отсканируйте его в
Telegram → *Настройки → Устройства → Подключить устройство*.

Альтернатива — вход по **коду из SMS/приложения** (нужен `PHONE`):

```sh
./tg_export --code-auth
```

Сессия сохраняется в `session.json`, при следующих запусках повторная
авторизация не требуется.

## Выбор чата и объёма выгрузки

После авторизации выводится список диалогов **по 25 на страницу**. Управление:

| Ввод | Действие |
|------|----------|
| номер | выбрать чат для экспорта (нумерация сквозная по всему списку) |
| `n` или Enter | следующая страница |
| `p` | предыдущая страница |
| `q` | выход |

Затем утилита спросит, **сколько последних сообщений экспортировать**. Введите
`0`, чтобы выгрузить всю историю целиком.

Прерывание по `Ctrl+C` безопасно; уже скачанные медиафайлы при повторном запуске
не загружаются заново.

## Для самостоятельной сборки из исходников

Нужен Go 1.26+.

Собрать и запустить:

```sh
go build -o tg_export .
./tg_export
```

Или без сборки:

```sh
go run .
```

Релизные бинарники собираются автоматически в GitHub Actions при пуше тега вида
`v1.0.0` — см. [.github/workflows/release.yaml](.github/workflows/release.yaml).
